# 远期方向

## 受限智能体

现有纯逻辑层未来可以支持有限 observation/action schema：控制者只能读取规定的感官和内部状态，只能提交方向与逃逸意图。AI 不会获得完整地图或绕过身体限制。

## 同场与评测

在单机规则稳定、接口公开、基线 agent 和跨 seed 评分完成后，再研究人类与 agent 同场、开放只读状态、排行榜和可复现 benchmark。

## 更多生物学

趋光、昼夜节律、嗅觉、信息素、觅食和捕食者学习都可能成为未来模块。进入产品前必须证明它们改变了玩法选择，而不是只增加术语。

## 多人

多人或大逃杀是远期架构方向，不是当前线上能力。它需要服务器权威模拟、断线与公平性设计、观测权限和完整安全评估。
